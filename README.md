# currency-converter
Currency Converter Using API

The Currency Converter is a web-based application developed to convert currencies from one country to another using real-time exchange rates fetched from an external API. The main purpose of this project is to provide users with a fast, simple, and accurate way to calculate currency values across different countries.

This application integrates a Currency Exchange Rate API to fetch the latest available exchange rate data dynamically. Users can select the source currency and target currency, enter the amount they wish to convert, and get the converted value instantly. Instead of relying on fixed exchange rates, the application retrieves updated exchange rate information from the API, making the conversion process more reliable and efficient.

The project provides a user-friendly interface that makes currency conversion easy for students, travellers, businesses, and anyone dealing with international currencies.

Key Features
API Integration: Fetches exchange rate data from an external currency exchange API.
Real-Time Exchange Rates: Retrieves the latest available exchange rates.
Multiple Currencies: Supports conversion between various international currencies.
Instant Conversion: Displays the converted amount based on the entered value.
User-Friendly Interface: Provides a simple and interactive design.
Dynamic Data: Uses API responses instead of manually stored exchange rates.
Technologies Used
HTML – For creating the structure of the application.
CSS – For styling and designing the user interface.
JavaScript – For handling user interactions, API requests, and currency calculations.
Currency Exchange Rate API – For fetching updated exchange rate information.
Working of the Project
The user selects the currency they want to convert from.
The user selects the target currency.
The user enters the amount to be converted.
JavaScript sends a request to the currency exchange API.
The API returns the latest available exchange rate data.
The application calculates and displays the converted amount.
Conclusion

The Currency Converter project demonstrates the practical implementation of API integration, asynchronous JavaScript, and dynamic data handling in web development. It helps users perform currency conversions conveniently while providing hands-on experience in working with external APIs and processing JSON data.
